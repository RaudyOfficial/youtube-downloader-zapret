# YouTube Downloader (zapret + DoH)

Портативный скрипт для скачивания видео с YouTube в России в обход блокировок ТСПУ/DPI с помощью [Flowseal/zapret](https://github.com/Flowseal/zapret-discord-youtube).

**Текущая версия: 1.2.1**

## Что внутри репозитория

| Папка / файл | Назначение |
|---|---|
| `scripts/downloader.ps1` | Основной скрипт на PowerShell |
| `scripts/launch.cmd` | Запуск двойным кликом (вызывает PowerShell) |
| `proxy/doh_proxy.py` | Локальный DoH-прокси (обходит подмену DNS) |
| `tools/` | Сюда нужно положить `yt-dlp.exe` (не входит в репозиторий из-за размера) |
| `tools/ffmpeg/` | Сюда нужно положить `ffmpeg.exe`, `ffplay.exe`, `ffprobe.exe`, если FFmpeg не установлен в `C:\ffmpeg\bin` |
| `zapret/` | Рабочая конфигурация zapret (стратегия ALT11) |

## Быстрый старт

1. **Склонируйте репозиторий** или скачайте ZIP и распакуйте в любую папку.
2. **Скачайте yt-dlp.exe** (файл слишком большой для репозитория):
   - [yt-dlp.exe](https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe) → положите в `tools\`
3. **Установите FFmpeg** (обязательно): в `C:\ffmpeg\bin` или положите `ffmpeg.exe`, `ffplay.exe`, `ffprobe.exe` в `tools\ffmpeg\`.
4. **Проверьте Python 3** — он нужен для DoH-прокси; команда `py --version` или `python --version` должна работать.
5. Запустите `scripts\launch.cmd` **от имени администратора** (права нужны для zapret).
6. Вставьте ссылку на видео (`youtube.com/watch?v=...` или `youtu.be/...`) — вручную или через **Ctrl+V**.
7. Нажмите **Tab**, выберите качество стрелками **← →** (144p / 360p / 720p / 1080p / MP3) и нажмите **Enter** — скачивание начнётся из любого режима.
8. После завершения: **Enter** — новое видео, **Esc** — выход.
9. Видео появится в папке **Загрузки / Downloads текущего пользователя**.

## Управление

| Клавиша | Действие |
|---|---|
| ввод с клавиатуры / **Ctrl+V** | ссылка на видео |
| **Tab** | переключение режима: ссылка ⇄ качество |
| **← →** | выбор качества (в режиме «качество») |
| **Enter** | начать скачивание (работает в обоих режимах) |
| **Esc** / Ctrl+C | выход |

## Как это работает

- **zapret** обходит DPI-блокировку трафика к YouTube.
- Обычный DNS в России подменяется ТСПУ, поэтому скрипт временно поднимает локальный **DoH-прокси** (`proxy\doh_proxy.py`), который разрешает домены через DNS-over-HTTPS. yt-dlp обращается к сети через этот прокси, поэтому обход zapret остаётся сквозным.
- После скачивания скрипт **останавливает свой DoH-прокси** и **закрывает zapret**, если запустил его сам. Если zapret был запущен вами до скрипта — он останется работать.

## Требования

- Windows 10 или 11
- **Права администратора** — нужны для запуска zapret (он использует WinDivert для фильтрации сетевого трафика)
- [yt-dlp.exe](https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe) — положите в `tools\`
- **FFmpeg** — обязателен: установите в `C:\ffmpeg\bin` или положите файлы в `tools\ffmpeg\`
- **Python 3** — обязателен для DoH-прокси (`py` или `python` в PATH)

## Если что-то не работает

- Убедитесь, что антивирус не блокирует `winws.exe` и `yt-dlp.exe`.
- Если скрипт пишет, что не найден `ffmpeg.exe` — установите его в `C:\ffmpeg\bin` или положите `ffmpeg.exe`, `ffplay.exe`, `ffprobe.exe` в папку `tools\ffmpeg\`.
- Если скрипт пишет, что не найден Python — установите Python 3 и добавьте его в PATH.
- Если YouTube не открывается — проверьте, что в папке `zapret/` лежит `general (ALT11).bat` и все файлы из `bin/` и `lists/`.
- Запускайте `launch.cmd` от имени администратора, иначе zapret не сможет запуститься.

Все три проекта — программы с открытым исходным кодом. Ссылки ведут на их официальные репозитории.
