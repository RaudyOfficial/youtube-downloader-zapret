# Changelog

## [1.2.1] — Живой ввод и режимы Tab

- Интерфейс перерисовывается сразу после каждого нажатия клавиши (раньше — только по Enter)
- Ввод ссылки и смена качества отображаются в реальном времени
- Курсор `▏` в поле ссылки
- Режимы: **Tab** переключает фокус «ссылка ⇄ качество», **Enter** начинает скачивание в обоих режимах
- Подсветка активного поля и выбранного качества зависит от фокуса
- Подсказки внизу меняются под текущий режим

## [1.2.0] — Тёмный терминальный интерфейс

- Новый дизайн по референсу `ref_design.png`: тёмный экран, крупный логотип, центрированные элементы
- Логотип «yt-dlp» из блочных символов с красной иконкой YouTube
- Поле ввода ссылки с синей полосой фокуса и плейсхолдером (ввод, Backspace, Ctrl+V)
- Выбор качества стрелками ← →, выбранная кнопка подсвечивается белым
- Логи с временем, тегами `[info]` / `[download]` и автоскроллом
- Прогресс-бар с реальным прогрессом загрузки и процентом
- TUI на чистом ANSI без внешних модулей; полноэкранный режим с восстановлением консоли
- Вся логика версии 1.1.0 сохранена: zapret, DoH-прокси, yt-dlp, ffmpeg, папка Загрузки

## [1.1.0] — TUI-меню и интерактивный режим

- Интерактивное терминальное меню (TUI-стиль), программа не закрывается после скачивания
- Возврат в меню и продолжение работы после завершения скачивания
- Пункт «Установить зависимости» со ссылками на yt-dlp и FFmpeg
- Показ текущей версии приложения
- Все функции версии 1.0 сохранены

## [1.0.0] — Первый релиз

- Скрипт для скачивания видео с YouTube через yt-dlp
- Обход блокировок ТСПУ/DPI через zapret (стратегия ALT11)
- Локальный DoH-прокси для обхода подмены DNS
- Выбор качества: 144p, 360p, 720p, 1080p, только аудио (mp3)
- Автоматический поиск ffmpeg в C:\ffmpeg\bin или tools\ffmpeg\
- Сохранение в папку Загрузки / Downloads текущего пользователя
- zapret запускается автоматически, если не запущен
- После скачивания прокси закрывается; zapret останавливается, только если его запустил скрипт
